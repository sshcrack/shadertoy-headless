ShaderToy.toml is the canonical editable project manifest.

The checked/generated JSON Schema describes its keys, types, enums, and
documentation:

  shadertoy docs manifest --schema

Projects generated by the CLI include:

  #:schema ./.shadertoy/shadertoy.schema.json

and a .taplo.toml association, so VS Code extensions such as Taplo / Even Better
TOML can provide validation and completion.

When the CLI loads a project that already contains that generated local schema,
it automatically replaces the file if it differs from the schema embedded in
the installed CLI. Projects without a local schema are not modified.

Semantic checks that JSON Schema cannot express (for example graph cycles and
whether a referenced pass exists) are enforced by:

  shadertoy check


Shared GLSL includes
--------------------

Quoted includes are expanded before native compilation:

  [shader]
  include_dirs = ["shaders/lib"]

  # in shaders/ocean.frag
  #include "waves.glsl"

Resolution order is the including file's directory first, followed by
shader.include_dirs. Include paths must remain inside the project root. Cycles,
missing includes, and root escapes are validation errors.

Custom uniforms
---------------

Declare project-level parameters once:

  [[uniform]]
  name = "wave_height"
  type = "float"
  default = 1.0
  min = 0.0
  max = 4.0
  step = 0.05

Supported types are float, int, bool, vec2, vec3, and vec4. The CLI injects the
corresponding GLSL uniform declaration. Defaults apply to check/render/preview;
deterministic commands can override values with:

  shadertoy render --set wave_height=1.75

A [[test]] may provide a `uniforms` table to override declared values for only
that case.

Regression tests
----------------

Deterministic tests live in the same manifest:

  [[test]]
  name = "ocean-frame-120"
  frame = 120
  reference = "tests/ocean-frame-120.png"
  tolerance = 0.002

  [[test]]
  name = "spectrum-stability"
  pass = "spectrum"
  frames = [0, 60, 120]
  resolutions = [[640, 360], [1280, 720]]
  assert_no_nan = true
  assert_no_inf = true
  assert_deterministic = true
  assert_resolution_independent = true
  raw_tolerance = 0.0

Run shadertoy test; shadertoy test --update intentionally rewrites visual
reference PNGs.
